# 市场与交易

## 市场模型

市场挂在 `Game.market` 上，常驻挂单：每种货物始终至少存在若干卖单与买单，价格由市场生成并随时间波动。

- 卖单：对方卖出，玩家买入，车辆送货来。
- 买单：对方买入，玩家卖出，车辆上门取货。
- 每张单对应一种货物和固定数量，价格按箱计。
- 同种货物的买卖价通常不同且随时变化，价差与时机构成交易利润。

收益来自买卖差价。

## 接单与装卸位

- 通过 `Game.market.take(order_id)` 接单，订单转入 `Game.my_orders()`。
- 接单前提是存在空闲装卸位；接单即预留一个装卸位，车辆下一 tick 出现并占用。
- 多个装卸口时车辆随机占用一个空闲口，首期不提供指定装卸口。
- 卖单（买入）接单时立即支付货款；买单（卖出）在车辆装满离场时收款。
- 已接订单可取消（`Game.market.cancel`）：条件是车辆恢复到出现时的状态——买入单车满、卖出单车空，同类型同数量即可，装回的箱子不必是原箱。取消即时生效，车辆消失、装卸位释放；取消的订单不回到市场。接单当 tick 即可取消，车辆未出现时按订单初始状态判定。
- 取消收取订单金额一定比例的手续费（比例随平衡，退款下限为 0）：卖单（买入）从退款中扣除；买单（卖出）从金币扣除，不足部分自动计入欠款。

## 车辆与离场

- 车辆只在接单后出现并占用一个装卸位。
- 入库车卸空即离场，出库车装满即离场：清空或装满发生在结算阶段，同一次结算内完成离场、订单完成与收款、装卸位释放（顺序见 [Tick、动作与电力](03-simulation-and-actions.md)），下一 tick 可接新单。
- 装卸位被占用期间不能在其上接新单，占口即机会成本惩罚。
- 买入的货物在卸离车辆前不可销毁；卸下后即归玩家，可存储、卖出或销毁止损。

## 货物通用

- 每箱货物只区分类型；同类型箱子完全可互换。
- 车辆只接受其订单类型的货物：类型不符的 give 被拒绝；往入库车装回同类型货物、从出库车取回货物，用于恢复可取消状态。
- 买单只校验货物类型与数量，任意同类型箱子均可交付。
- 由此形成经营策略：低价囤货占用仓容与资金、高价卖出；廉价卖单与优价买单同时出现时，可不入库直接倒手（直通转运）。
