# 世界与空间规则

## 已确定方向

仓库使用二维网格，玩家可以查看整个仓库。机器人每 tick 最多沿上、下、左、右移动一格。建筑、机器人和地面货物占格，同一格不能同时存在这些对象。

机器人通过上下左右相邻格与建筑或对象交互，不允许斜向交互。

## 地面占位与容纳关系

当前基线将地面实体和被容纳的货物分开：

| 对象 | 地面占位 | 容纳能力 |
| --- | --- | --- |
| 机器人 | 一格 | 首期携带一箱 |
| 货架 | 一格 | 基线最多四箱 |
| 充电桩 | 一格 | 不存货 |
| 装卸口 | 占用仓库空间，具体尺寸待定 | 关联占用车辆 |
| 地面货物 | 每箱一格 | 无 |
| 被携带或存储的货物 | 不额外占用地面格 | 属于机器人、货架或车辆 |

机器人不能走进建筑、其他未离开的机器人或地面货物所在格。货架内、机器人携带中和车辆内的货物不另外占据地面格子。

## 货架

- 每个货架占一格，基线最多容纳四箱，具体数量随原型平衡。
- 机器人从货架旁按货物 id 存取，见 [API 设计](08-api-design.md)。
- 容量不随货物类型变化。

## 充电桩

机器人在相邻格充电，无须进入充电桩所在格。一个充电桩每 tick 最多服务一台机器人；充电持续多个 tick。

多台机器人同时请求同一充电桩时的分配规则待定。电力规则见 [Tick、动作与电力](03-simulation-and-actions.md)。

## 装卸口与车辆

车辆只在玩家接单后出现，占用一个装卸位；机器人从装卸口相邻位置装卸，卸空或装满即离场并释放装卸位。多装卸口时车辆随机占用空位，首期不提供指定装卸口。

首期使用可同时服务买入与卖出的通用装卸口。尺寸、是否必须位于边界、交互面仍待明确。完整规则见 [市场与交易](04-orders-and-logistics.md)。

## 货物

- 首期以箱为单位，不拆箱、不合并箱。
- 每箱只区分货物类型；同类型箱子完全可互换。
- 不同种类的货物暂不具有重量、体积、保质期或品质差异。
- 地面货物可临时存放，但会阻塞通道；通过相邻格拾起和放下。
- 货物支持主动销毁，规则见 [经营、商店与成长](06-economy-and-progression.md)。

建筑购买和销毁约束见 [经营、商店与成长](06-economy-and-progression.md)。
