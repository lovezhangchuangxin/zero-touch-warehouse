## 设计状态

- **已确定方向**：用户明确提出或明确认可的产品方向。
- **当前基线**：讨论中提出、用于串联玩法的推荐规则；可继续调整，不应当成最终定案。
- **待定**：尚未决定的细节，实施前需要补齐。

明确确定的方向包括：单机 2D 仓库物流编程游戏；Python / JavaScript 同步控制整个世界；按 tick 运行；移动不耗电；网格占位和正交交互；商店与销毁；以持续经营为主、教学关卡引导入门；API 以 `Game` 全局对象为入口，两种语言同名 snake_case。迷宫等额外小游戏不属于本期范围。

除明确标注外，各主题中的细化方案属于当前基线。[API 设计](08-api-design.md)已将接口命名与签名列为当前基线；其余文档中的 API 名称、报酬和时间示例仅用于解释规则，不是最终接口或平衡参数。订单机制沿用上一轮推荐方案整理，具体规则仍可调整。

## 共用术语

| 术语 | 含义 |
| --- | --- |
| tick | 世界的一次逻辑时间步 |
| 箱 | 首期货物的最小搬运和存储单位 |
| 合同 / 订单 | 玩家接取的一份完整仓储物流承诺，本文中两者同义 |
| 运输任务 | 合同产生的入库或出库安排，无须再次接单 |
| 到达 | 车辆进入仓库外等待队列 |
| 靠泊 | 车辆占用装卸口，允许机器人装卸 |

跨主题未决事项统一收录在 [首期范围与待定事项](07-scope-and-open-questions.md)，避免把讨论中的空白隐式变成实现规则。
