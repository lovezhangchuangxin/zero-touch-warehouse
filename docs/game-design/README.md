## 设计状态

- **已确定方向**：用户明确提出或明确认可的产品方向。
- **当前基线**：讨论中提出、用于串联玩法的推荐规则；可继续调整，不应当成最终定案。
- **待定**：尚未决定的细节，实施前需要补齐。

明确确定的方向包括：单机 2D 仓库经营编程游戏；Python / JavaScript 同步控制整个世界；按 tick 运行；移动不耗电；网格占位和正交交互；常驻商品市场、低买高卖；无期限借贷（按 tick 计息、随借随还）；商店与销毁（含货物）；以持续经营为主、教学关卡引导入门；API 以 `Game` 全局对象为入口，两种语言同名 snake_case。迷宫等额外小游戏不属于本期范围。

除明确标注外，各主题中的细化方案属于当前基线。[API 设计](08-api-design.md)已将接口命名与签名列为当前基线；其余文档中的 API 名称和数值示例仅用于解释规则，不是最终接口或平衡参数。

## 共用术语

| 术语 | 含义 |
| --- | --- |
| tick | 世界的一次逻辑时间步 |
| 箱 | 首期货物的最小搬运和存储单位 |
| 买单 / 卖单 | 市场挂单：买单是对方收购（玩家卖出），卖单是对方出售（玩家买入） |
| 接单 | 将市场挂单转入自己的订单，预留并占用一个装卸位 |

跨主题未决事项统一收录在 [首期范围与待定事项](07-scope-and-open-questions.md)，避免把讨论中的空白隐式变成实现规则。
