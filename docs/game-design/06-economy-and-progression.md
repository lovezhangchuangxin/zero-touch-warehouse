# 经营、商店与成长

## 初始资源

已确定玩家初始拥有一定金币、一台机器人、一个充电桩和一个装卸位。初始没有货架，前期以地面暂存为主。具体金币、电池初始状态和地图大小待定，初始金币须覆盖市场最便宜的整单。

## 金币循环

当前基线为低买高卖：接卖单买入货物（资金变为库存），接买单卖出货物（库存回笼资金），赚取差价。货物是流动资金，库存与设备争夺同一笔金币。金币还用于购买机器人、充电桩、货架和装卸位。

金币不足时可借贷（`Game.borrow`）：无期限、按 tick 计息、可随时部分或全部归还（`Game.repay`）。里程碑 3 冻结：利率 0.1%/tick 复利、信用额度 1000（高于机器人价 650 的解围成本）。借贷是零金币零库存时重启经营的保底。

新增机器人提高并行搬运能力，但也带来交通和充电压力；新增货架增加存储能力，但占用地面；新增装卸位增加并行接单能力，同时需要机器人供给能力匹配。

设备定价与市场价差需要共同平衡，避免单一设备成为没有取舍的最优投资。

## 商店与建造

已确定支持购买机器人及建筑，通过 `Game.destroy` 销毁对象与货物。

当前基线：

- 界面和代码均可进行管理操作。
- 购买后放置到合法空格。
- 购买、放置和销毁的资金与占位校验必须可查询失败原因。
- 购买即时扣费、即时建成生效；同一 tick 内的管理操作按调用顺序结算。管理操作的完整语义见 [API 设计](08-api-design.md)。

## 销毁

当前基线限制：

| 对象 | 销毁前提 |
| --- | --- |
| 机器人 | 必须空载 |
| 货架 | 所有货物清空 |
| 货物 | 无前提，不退款；未卸离车辆的购入货物除外 |
| 装卸位 | 没有占用车辆 |
| 充电桩 | 可销毁；已受理的充电动作在结算时失败并返回原因 |

设备销毁退还半价（冻结）。货物销毁无退款，是库存错判与资金占用的最终止损阀：买错的货销毁后释放仓位，市场永远有挂单，经营随时可以重启。

## 教学与主线

已确定持续经营为主，教学关卡引导入门。建议按依赖关系逐步教授：

1. 查询位置，单步移动机器人。
2. 从车辆取货、放到地面暂存，再装车交付。
3. 电量检查与充电。
4. `loop()`、全局状态与动作结果处理。
5. 查询市场，买入与卖出。
6. 地面存货堵塞通道，引入货架提升存储密度。
7. 多机器人任务分配、拥堵处理。
8. 商店扩建与自动接单策略。

以上为教学内容顺序建议，不规定关卡数量、解锁门槛或是否强制完成教程。

## 试错与恢复

支持暂停、单步、存档和重开，让玩家敢于修改代码。错误的主要代价是资金占用与吞吐损失：买错的货可销毁止损，接错的单恢复车辆原状后可取消（少量手续费），金币耗尽可借贷重启，不会直接结束经营。

金币不可为负，所有支出前置校验，卖单取消手续费不足时自动计入欠款。不能依赖出售最后一台机器人等隐式补救机制保证游戏可继续。
