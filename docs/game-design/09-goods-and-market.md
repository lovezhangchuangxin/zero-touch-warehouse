# 货物与市场参数

本篇定义货物类型、价格模型与经济不变量，结构为当前基线；全部数值为示例锚点，随原型平衡。

## 货物类型

首期三种货物，以单价量级、整单数量、波动特性区分，各对应一个成长阶段的玩法角色：

| 标识 | 类型 | 单价（示例） | 常见整单 | 波动 | 角色 |
| --- | --- | --- | --- | --- | --- |
| `water` | 矿泉水 | 3–6 | 8–16 箱 | 平稳 | 前期主力：薄利多销，练吞吐、路线与多机器人协作 |
| `battery` | 电池 | 10–20 | 4–8 箱 | 中等 | 中期主力：第一个囤货投机品类，货架投资开始有意义 |
| `chip` | 芯片 | 40–80 | 2–4 箱 | 大，挂单稀疏 | 后期资金蓄水池：单格货架锁住高额资金，配合借贷形成杠杆玩法 |

单价越高、整单越小、资金密度越高，存储压力从占用地面转为占用资金。节令类周期货物留作后续扩展首选。

## 价格模型

1. 每种货物有基准价，按均值回归随机游走演化：`P(t+1) = P(t) + k·(P̄ − P(t)) + σ·噪声`，其中 `P̄` 为回归锚价、`k` 为每 tick 回归系数、`σ` 为每 tick 波动幅度、噪声为零均值单位噪声。基准价逐 tick 演化，挂单随刷新围绕当前基准价重采样，价差率以基准价为基准。价格因此有界，且天然形成低于均值买入、涨回卖出的周期。
2. 挂单价围绕理论 bid/ask 线（基准价 ∓ 半价差）随机分散，板面上始终存在相对划算的挂单，扫描比价有真实收益。
3. 买卖价差是即时往返税：同一时刻买入再卖出必亏约一个价差（示例 20%–40%），低买高卖必须跨时间。
4. 数量错配：买入单量大（8–16 箱），卖出单量小而频繁（2–6 箱）。买进的货物必然需要暂存等待多次卖出，仓储是经营必需，直通转运只覆盖零星巧合。
5. 刷新节奏：板面每 30–60 tick 部分刷新，每类型每侧常驻 2–4 张挂单。
6. 权威金额以定点整数存储与结算（内部最小单位），利息、手续费等逐笔舍入规则随规则版本冻结；对玩家仍以金币数值显示（见[技术架构 02](../architecture/02-simulation-core.md)）。

## 经济性质

- 无持有税与经常性支出，设备购齐后金币只增不减：压力来自玩家主动选择的库存风险与装卸位机会成本，属自选压力的沙盒取向。
- 单周期毛利目标（示例）：矿泉水 10%–20%，电池 20%–30%，芯片 30%–50% 且低频。

## 数值锚点（示例，随平衡）

| 项 | 锚点 |
| --- | --- |
| 初始金币 | 300 ≈ 最便宜整单（矿泉水约 50）×2 加余量 |
| 机器人 | 500–800，第一个经营里程碑 |
| 货架 / 充电桩 / 装卸位 | 150–200 / 300 / 500 |
| 取消手续费 | 订单额的 10% 上下，须大于短期典型跌幅 |

## 不变量

市场生成器必须满足的验收标准，优先级高于任何具体数值：

1. 任一时刻同类型 bid < ask，瞬时套利永不成立。
2. 买卖价差恒大于取消手续费率。
3. 均值回归参数保证价格有界且为正。
4. 每类型双向挂单常驻。
5. 买卖数量错配恒成立。
