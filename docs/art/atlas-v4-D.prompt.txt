Use case: production sprite sheet for a 2D grid warehouse game. Produce an isolated game sprite atlas, NOT a scene or concept screenshot. Style reference: the attached image "warehouse-concept-v3.png". Match its crisp dark outlines, clean simplified painted surfaces, soft bevel shading, teal accents and warm yellows, so these small pieces read as part of the same game world. Polished cartoon-illustrated game sprites, NOT realistic materials.

FORMAT RULES (strict):
1. Fully transparent background: true alpha-channel transparency (RGBA PNG). Absolutely no checkerboard pattern, no solid backdrop color anywhere.
2. These are floating icons and effects: NO contact shadows.
3. Fixed near-top-down orthographic camera. Light from the upper left. Do not rotate sprites in the image plane.
4. Fill exactly the slots described below, each exactly once, complete and uncropped, centered in its slot, generous equal padding. Never invent extra objects; never duplicate a slot.
5. Animation sequences are drawn left to right within their row: all frames of a sequence are the same size and share the same center position, aligned so they can be played in place.
6. Exactly 4 columns by 4 rows, 16 slots. High resolution.
7. No text, no numbers, no UI panels, no borders, no grid lines, no slot dividers, no watermark. The ONLY glyph-like shapes allowed are the exclamation mark, the check mark and the letter Z explicitly listed below.

Row 3 — status icons, each one centered item: (3,1) red rounded exclamation mark; (3,2) green rounded check mark; (3,3) yellow battery icon standing upright, mostly full, dark outline; (3,4) THE SAME battery icon, nearly empty — the last cell segment turns red and the icon gets a thin red outline glow. NO large red halo, NO smoke, NO aura blobs around it.
